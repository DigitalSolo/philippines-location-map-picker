# Release Notes v1.0.65

This release makes the package easier to consume from plain HTML/PHP pages.

## Highlights

- New `mountStaticLocationMapPicker` alias for the reusable static component.
- One DOM element integration: place a mount div inside a form and call the UMD helper.
- Auto-created package-owned hidden submit fields.
- Updated Quick Start documentation and UMD example.
- Static reverse-fill fallback keeps the selected barangay when exact cached geometry is missing.
- Demo layout places Reusable Component above Quick Start.
- Final Browser QA Pass is minimized by default.

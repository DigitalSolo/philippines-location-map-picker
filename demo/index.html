Quick start: no import or bundler required

Copy the package folder into your public vendor path, include the CSS and UMD script, add one mount div, then initialize the picker from window.PhilippinesLocationMapPicker. The package creates form submit fields automatically when mounted inside a form.

  1. Deploy dist/ and data/ under /assets/vendor/philippines-location-map-picker/.
  2. Add the stylesheet, one mount element, and the UMD script shown below.
  3. Change only baseUrl, mount, field prefix, provider mode, and map options to match the host page.
  4. Use static mode for no-database installs, API mode for database-backed host apps, or hybrid mode for static dropdowns with database-backed reverse lookup.

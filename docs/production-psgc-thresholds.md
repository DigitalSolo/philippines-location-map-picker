# Production PSGC Thresholds

Production hierarchy readiness expects complete PSGC hierarchy coverage.

Current thresholds are tracked by `tools/write-production-thresholds-report.js` and reported under:

```text
data/production-psgc-thresholds-report.json
demo/data/production-psgc-thresholds-report.json
```

Full production reverse-fill requires nationwide barangay geometry coverage. Limited-geometry releases can still be valid when they clearly document the limitation.
